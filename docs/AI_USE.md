# AI use

ETHGlobal requires disclosure of how AI was used.

- Design, architecture, and this document were drafted with an AI assistant (Hermes/Claude).
- Firmware and host code are written with AI assistance, then reviewed and tested by the team on the
  device; every claimed measurement in `README.md` comes from a run on the board.
- The Ash Desktop app (`app/`, Tauri + Svelte) was generated with the same assistant: Rust device
  link and service supervisor, Svelte UI, the intro timeline and its 43 MCU frames, the AppDir build
  script. Its behaviour was verified against the live board and the running service.
- No sponsor API shape is asserted without a doc or a live response captured during the event.
- Updates: append a line here each time a new component is generated with AI assistance.
